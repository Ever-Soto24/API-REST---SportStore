# API REST - SportStore

API REST desarrollada con Spring Boot para la gestión básica de una tienda deportiva.

## Tecnologías utilizadas

* Java
* Spring Boot
* Maven
* MySQL
* Docker
* Imsomnia

## Funcionalidades

* CRUD de productos
* CRUD de categorías
* CRUD de clientes
* CRUD de vendedores
* CRUD de ventas

## Endpoints principales

```text
/productos
/categorias
/clientes
/vendedores
/ventas
/detalle-ventas
```
